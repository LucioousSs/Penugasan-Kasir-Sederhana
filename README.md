# Program Kasir Sederhana

Program kasir sederhana untuk menghitung total belanja beserta diskonnya.

## Fitur

- Input harga barang dan jumlah belanja
- Hitung total belanja lewat tombol **Harga Total**
- Diskon otomatis 10% untuk total belanja di atas Rp100.000

## Tech Stack

- HTML
- CSS
- JavaScript (logika perhitungan, ditulis inline di `index.html`)

## Menjalankan

Buka `index.html` di browser. Tidak perlu server atau build step.
